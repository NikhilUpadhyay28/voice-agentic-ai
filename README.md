# Voice-First Multilingual Agentic AI

A web-based voice-first AI system built using Python and Flask that supports Hindi, Bengali, and Odia.

## Features
- Voice input and output
- Speech-to-text and text-to-speech
- Agentic workflow with planning and tools
- Conversation memory
- Failure handling

## Tech Stack
- Python, Flask
- SpeechRecognition, gTTS
- LangChain
- JavaScript, HTML
- WSL

## Run
```bash
pip install -r requirements.txt
python app.py
